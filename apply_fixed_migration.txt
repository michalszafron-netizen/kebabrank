# Steps to Apply Corrected Migration

1. Log in to Supabase dashboard: https://app.supabase.com/
2. Select your project
3. Go to SQL Editor
4. Copy the entire content from fixed_migration.sql
5. Paste and execute in the SQL Editor (this will first drop then recreate the function)
6. Verify the function was created:
```sql
SELECT * FROM pg_proc WHERE proname = 'get_city_rankings_with_latest_ratings';
```

7. Test the function with:
```sql
SELECT * FROM get_city_rankings_with_latest_ratings(1, 5, 0);
```

8. Once confirmed working, restart your Flask application

Note: The function now correctly matches the table column types (character varying(255) instead of text.
