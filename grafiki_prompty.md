# 🛠️ WSKAZÓWKI TECHNICZNE

## Jak używać promptów w Nano Banana 2

1. **Kopiuj prompt** dla danego miejsca
2. **Wklej do Nano Banana 2** jako input
3. **Wygeneruj 3–4 warianty** i wybierz najlepszy
4. **Tekst dodaj ręcznie** w Canva po wygenerowaniu tła:
   - `🏆 #1 Kebab w [MIASTO] 2026`
   - `[Nazwa miejsca]`
   - `KebabRank.com`
   - `Wynik: XX.X/100`

## Spójność między miastami — elementy stałe

| Element | Wartość |
|---------|---------|
| Format | 9:16 pionowy (Instagram Story) |
| Tło | Ciemny granat / czerń |
| Akcent | Pomarańczowy (#ff6a00) |
| Trofeum | Złote (#1), Srebrne (#2), Brązowe (#3) |
| Odznaka #4-5 | Ciemnoszara z pomarańczowym obrysem |
| Czcionka (Canva) | Inter Bold / Montserrat Bold |

## Kolejność produkcji grafik

1. Kraków → Warszawa → Wrocław *(największy ruch na portalu)*
2. Gdańsk → Poznań → Łódź
3. Katowice → Szczecin → Bydgoszcz
4. Reszta miast
